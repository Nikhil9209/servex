## 🌟 Overview

**ServeX** is a modern, responsive web application that connects customers with trusted local service providers. Whether you need emergency plumbing repairs, electrical work, AC maintenance, mobile phone repairs, home cleaning, or tutoring services - ServeX makes it easy to find and book reliable professionals in your area.

### ✨ Key Features

- **🔍 Smart Service Discovery**: Browse through 6 major service categories with detailed descriptions
- **⚡ Real-time Availability**: Check service provider availability and response times
- **🎨 Modern UI/UX**: Beautiful, responsive design with smooth animations powered by Framer Motion
- **📱 Mobile-First**: Optimized for all devices with seamless cross-platform experience
- **🚀 Fast Performance**: Built with Vite for lightning-fast loading and development
- **🔒 Secure**: Modern React architecture with proper error handling and validation

## 🚀 Quick Start

### Prerequisites

- **Node.js** (version 16.0 or higher)
- **npm** or **yarn** package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/servex.git
   cd servex
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:5173` to see ServeX in action!

### Available Scripts

```bash
npm run dev      # Start development server
npm run build    # Build for production
npm run preview  # Preview production build
npm run lint     # Run ESLint
```
